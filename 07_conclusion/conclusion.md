El desarrollo de esta actividad nos permitió, primero que nada comunicarnos, observar y analizar como equipo, así como también aprender el uso práctico de un Data Mart mediante consultas SQL avanzadas, integrando CTEs, funciones de ventana y procedimientos almacenados para responder a preguntas de negocio complejas.
